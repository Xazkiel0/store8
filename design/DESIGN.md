# YourStore Design System

> Category: E-Commerce Admin & Storefront
> Surface: Web & Dashboard

## Color Palette

| Role | Name | Hex | OKLCh | Usage |
| --- | --- | --- | --- | --- |
| background | Background | `#ffffff` | `oklch(0.99 0.002 240)` | Page canvas & body |
| foreground | Foreground | `#0f172a` | `oklch(0.20 0.02 260)` | Main body text and titles |
| accent | Accent | `#1677ff` | `oklch(0.60 0.20 250)` | Primary actions, chart highlights, active nav |
| surface | Surface | `#f8fafc` | `oklch(0.98 0.004 240)` | Cards, tables, sidebar panels |
| muted | Muted | `#64748b` | `oklch(0.55 0.03 250)` | Subtitles, table headers, metadata |
| border | Border | `#e2e8f0` | `oklch(0.90 0.01 250)` | Borders, dividers, table rows |

## Typography
- **Display:** Inter (fallbacks: system-ui, -apple-system, Segoe UI, Roboto, sans-serif)
- **Body:** Inter (fallbacks: system-ui, -apple-system, Segoe UI, Roboto, sans-serif)
- **Mono:** ui-monospace, SF Mono, Menlo, monospace

## Layout & Rules
- **Radius:** 8px
- **Border:** 1px solid `--border`
- **Grid:** 8px baseline grid
- **Components:** Button, Card, Form, Navigation, Table, StatCard, ChartCard
